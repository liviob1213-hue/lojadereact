O QUE É
Painéis lado a lado: o ativo se abre e os outros viram faixas com o título na vertical. O conteúdo é revelado como cortina, sem espremer. Passa sozinho com barra de tempo.

ONDE SE APLICA
Página de exemplo: "acervo.", coleções da semana de uma plataforma cultural.
Serve também para: destaques da home, categorias, cases de portfólio, planos, depoimentos.

COMO MEXER NA PÁGINA DE EXEMPLO
passar o mouse ou clicar numa faixa, setas do teclado, botões ‹ ›. O autoplay pausa com o mouse em cima.

------------------------------------------------------------------------
COMO USAR
------------------------------------------------------------------------
1. Copie a pasta "17-sanfona-de-paineis" para o seu projeto
   (ou copie o código completo do fim deste documento para um arquivo .html).
2. Abra o index.html com dois cliques. Não precisa instalar nada,
   não precisa de internet, não tem npm nem build.
3. Para levar só o efeito para a sua página, copie:
   - o bloco <style> (as regras marcadas como parte do efeito),
   - o HTML do componente,
   - o <script> do fim do arquivo.
4. Funciona em qualquer site, em React, Vue, Svelte, Next ou dentro
   de um iframe: não depende de nenhum framework.

Quem ligou "reduzir movimento" no sistema recebe a mesma tela, sem a
animação (prefers-reduced-motion respeitado).

FICHA TÉCNICA (o que define o efeito e como ele foi feito)
------------------------------------------------------------------------
EFEITO 17 — Sanfona de painéis
Referência: a ideia de "flex carousel" (painéis lado a lado em que o ativo se
abre e os outros viram faixas). Escrito do zero para a FULGOR, sem código de
terceiros.

O que define o efeito:
  1. todos os painéis ficam SEMPRE na tela: o ativo ocupa quase toda a largura
     e os outros viram faixas estreitas com o título na vertical;
  2. trocar não desliza nada para fora: um painel cresce enquanto o outro
     encolhe, ao mesmo tempo, e a soma das larguras nunca muda;
  3. o conteúdo do painel NÃO é espremido enquanto ele cresce — ele tem largura
     própria e vai sendo revelado, como uma cortina abrindo;
  4. passa sozinho, com uma barra de tempo no painel ativo, e para quando o
     mouse está em cima.

Como é feito: flex-grow animado (o navegador interpola o número) com uma curva
de mola. O miolo de cada painel tem largura fixa igual à do painel aberto,
ancorado à esquerda, e o painel corta o excesso com overflow:hidden. O texto
entra em sequência só depois que o painel já abriu boa parte.

O que costuma sair errado:
  - animar width em px: cada painel precisa saber o tamanho dos outros, e a
    soma "escorrega" no meio da troca;
  - deixar o texto com largura automática: ele quebra linha a cada quadro e
    pula enquanto o painel cresce;
  - o autoplay continuar contando com a aba escondida: aqui ele conta só o
    tempo visível, pelo próprio requestAnimationFrame.

<script>
(() => {
  const reduzido = matchMedia('(prefers-reduced-motion: reduce)').matches;

  // título, categoria, texto, meta, cores [a1, a2, a3, px, py]
  const COLECOES = [
    ['Noites de vidro', 'fotografia', 'Cidades depois da chuva, vistas pela janela de um ônibus vazio. Quarenta fotos, um único trajeto.', '40 obras · 12 min', ['#1b2a4a', '#5aa9ff', '#a35cff', '72%', '30%']],
    ['Terra vermelha', 'pintura', 'Telas grandes feitas com pigmento de barro coletado no mesmo rio onde a artista cresceu.', '18 obras · 9 min', ['#4a1d14', '#ff7a45', '#ffc46b', '60%', '40%']],
    ['Ruído branco', 'som', 'Gravações de campo de lugares onde quase nada acontece — e o que acontece mesmo assim.', '7 faixas · 34 min', ['#1f2622', '#d8ffe0', '#6fbf8f', '40%', '28%']],
    ['Casa de verão', 'arquitetura', 'Doze casas de praia desenhadas para ficar fechadas nove meses por ano, e abrir inteiras nos outros três.', '12 projetos · 15 min', ['#2c2a14', '#e9ff70', '#ff9d5c', '68%', '45%']],
    ['Mar aberto', 'cinema', 'Curtas filmados num único barco, com a mesma equipe, durante uma travessia de dez dias.', '5 filmes · 58 min', ['#0f2d33', '#4fe3d0', '#2a6dff', '55%', '32%']],
  ];

  const sanfona = document.getElementById('sanfona');
  const contador = document.getElementById('contador');
  const paineis = COLECOES.map(([titulo, cat, texto, meta, c], i) => {
    const b = document.createElement('div');
    b.className = 'painel';
    b.tabIndex = 0;
    b.setAttribute('role', 'tab');
    b.setAttribute('aria-expanded', 'false');
    b.setAttribute('aria-label', titulo);
    b.style.cssText = `--a1:${c[0]};--a2:${c[1]};--a3:${c[2]};--px:${c[3]};--py:${c[4]}`;
    b.innerHTML = `<div class="arte"></div>
      <div class="faixa"><b>${String(i + 1).padStart(2, '0')}</b><span>${titulo}</span></div>
      <div class="tempo"><i></i></div>
      <div class="miolo">
        <small style="--i:0">${cat}</small>
        <h2 style="--i:1">${titulo}</h2>
        <p style="--i:2">${texto}</p>
        <div class="acoes" style="--i:3"><span class="ir">Ver coleção</span><span class="meta">${meta}</span></div>
      </div>`;
    sanfona.appendChild(b);
    return b;
  });
  const barras = paineis.map((p) => p.querySelector('.tempo i'));

  let ativo = -1;
  function abrir(i) {
    i = (i + paineis.length) % paineis.length;
    if (i === ativo) return;
    ativo = i;
    paineis.forEach((p, j) => {
      p.setAttribute('aria-expanded', String(j === i));
      p.setAttribute('aria-selected', String(j === i));
    });
    contador.textContent = `${String(i + 1).padStart(2, '0')} / ${String(paineis.length).padStart(2, '0')}`;
    decorrido = 0;
    barras.forEach((b) => (b.style.transform = 'scaleX(0)'));
  }

  /* ---------------- autoplay que conta só o tempo visível ---------------- */
  const TEMPO = parseFloat(getComputedStyle(document.documentElement).getPropertyValue('--tempo'));
  let decorrido = 0, ultimo = performance.now(), pausado = false;
  function quadro(t) {
    const dt = Math.min(60, t - ultimo);   // aba escondida não "acumula" tempo
    ultimo = t;
    if (!pausado && !reduzido) {
      decorrido += dt;
      barras[ativo].style.transform = `scaleX(${Math.min(1, decorrido / TEMPO)})`;
      if (decorrido >= TEMPO) abrir(ativo + 1);
    }
    requestAnimationFrame(quadro);
  }

  // hover abre (com uma pequena espera, para atravessar a sanfona sem abrir tudo)
  let espera;
  paineis.forEach((p, i) => {
    p.addEventListener('pointerenter', (e) => {
      if (e.pointerType !== 'mouse') return;
      clearTimeout(espera);
      espera = setTimeout(() => abrir(i), 140);
    });
    p.addEventListener('pointerleave', () => clearTimeout(espera));
    p.addEventListener('click', () => abrir(i));
    p.addEventListener('focus', () => abrir(i));
  });
  sanfona.addEventListener('pointerenter', () => { pausado = true; });
  sanfona.addEventListener('pointerleave', () => { pausado = false; });

  sanfona.addEventListener('keydown', (e) => {
    if (e.key !== 'ArrowRight' && e.key !== 'ArrowLeft') return;
    e.preventDefault();
    const j = (ativo + (e.key === 'ArrowRight' ? 1 : -1) + paineis.length) % paineis.length;
    paineis[j].focus();
  });
  document.getElementById('antes').addEventListener('click', () => abrir(ativo - 1));
  document.getElementById('depois').addEventListener('click', () => abrir(ativo + 1));

  abrir(0);
  requestAnimationFrame(quadro);
})();
</script>
