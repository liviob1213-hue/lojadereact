Catálogo de efeitos

Catorze efeitos de interface, cada um extraído quadro a quadro de um vídeo de referência e reescrito em HTML, CSS e JavaScript puros. Cada pasta abre sozinha, com dois cliques, sem instalar nada.

O cabeçalho de cada arquivo diz de onde veio o efeito, o que o define e como foi feito.

Cada pasta é um efeito, num arquivo só. As técnicas estão no LEIAME.
